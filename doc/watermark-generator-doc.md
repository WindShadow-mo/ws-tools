# 图片水印生成器 — 功能说明文档

## 1. 概述

本工具为单文件 HTML 图片水印生成器，无需安装任何依赖，双击即可在浏览器中打开使用。
支持上传图片后添加各类水印，并提供多种预设模板，一键切换。
所有用户配置通过浏览器 Cookie 自动保存，有效期 30 天（仅在 http/https 协议下生效）。

---

## 2. 使用流程

1. 打开 `watermark-generator.html`
2. 点击或拖拽上传背景图片（支持 JPG / PNG / WebP / BMP）
3. 选择水印模板，或手动调整各项参数
4. 右侧实时预览效果
5. 点击「下载 PNG 图片」导出带水印的图片

## 3. 功能模块

### 3.1 图片上传

| 操作 | 说明 |
|------|------|
| 点击上传 | 点击上传区域，弹出文件选择框 |
| 拖拽上传 | 将图片文件拖入上传区域 |
| 移除图片 | 点击「移除」按钮，恢复默认画布（800×600） |

上传后画布尺寸自动同步为图片原始尺寸。

### 3.3 样式参数

| 参数 | 范围 | 默认值 | 说明 |
|------|------|--------|------|
| 水印文字 | 自由输入 | 仅供内部使用 | 支持多行（换行符分隔） |
| 字体 | 7 种中/英文字体 | 微软雅黑 | 黑体、宋体、楷体、仿宋等 |
| 字体大小 | 12–200px | 40px | 滑块实时调节 |
| 旋转角度 | -180°–180° | -30° | 水印文字倾斜方向 |
| 透明度 | 1%–100% | 20% | 值越小越淡 |
| 文字颜色 | 任意 HEX 色值 | #000000 | 颜色选择器 + 色值显示 |

> **平铺模式**：非网格模板始终为全图平铺（重复排列），无位置选择。

---

### 3.4 网格水印（专属控件）

点击「网格水印」模板后显示以下额外控件：

**图标选择**
提供 8 种 SVG 图标，显示在水印文字之前：

| 图标 | 说明 |
|------|------|
| ☎ 电话 | 手机号保护（默认） |
| ✉ 邮件 | 邮箱地址保护 |
| 💬 微信/聊天 | 微信号保护 |
| 🌐 网址 | 网站链接保护 |
| 🔒 锁/安全 | 安全声明 |
| ★ 星星 | 个性标注 |
| 📍 位置 | 地理位置保护 |
| ✕ 无图标 | 只显示文字 |

**网格大小**
- 范围：300–600px（默认 360px）
- 控制菱形网格单元的大小，值越大菱形越大、水印越稀疏

**网格线条粗细**
- 范围：3.0–15.0px（默认 8.0px）
- 控制菱形网格线条的宽度

> **文字分布**：约一半的菱形格内显示水印文字（稀疏棋盘分布），文字始终位于菱形几何中心。
> **旋转支持**：旋转角度在网格模板中同样生效，控制每个菱形内文字/图标的朝向。

---

### 3.5 配置持久化（Cookie）

| 条件 | 行为 |
|------|------|
| 协议为 `http://` 或 `https://` | 所有配置自动保存到浏览器 Cookie，有效期 30 天 |
| 协议为 `file://` 或其他 | 不保存，每次打开使用默认值 |

**自动保存时机**：任意控件 `change`、`blur`、图标选择时。
**恢复时机**：页面加载时自动读取 Cookie 恢复所有配置。

---

### 3.6 重置配置

点击「重置配置」按钮，所有参数恢复到默认值：

| 参数 | 默认值 |
|------|--------|
| 水印文字 | 仅供内部使用 |
| 字体 | Microsoft YaHei |
| 字体大小 | 40px |
| 旋转角度 | -30° |
| 透明度 | 20% |
| 文字颜色 | #000000 |
| 网格大小 | 360px |
| 网格线条粗细 | 8.0px |
| 图标 | 电话 |

重置后同步更新 Cookie。

## 4. 文件说明

| 文件 | 说明 |
|------|------|
| `watermark-generator.html` | 主程序（单文件，内含 CSS + JavaScript） |
| `watermark-generator-doc.md` | 本文档 |

> **技术要点**
> - 水印渲染：HTML5 Canvas 2D API
> - 图标渲染：SVG Path2D（不支持时回退为 Unicode 占位符）
> - 网格算法：两组对角线（`y=x+k·step` 与 `y=-x+m·step`）形成菱形网格，文字放置于 `(k+m)` 为奇数的菱形单元中心
> - 配置存储：`document.cookie`，JSON 序列化，`encodeURIComponent` 编码

---

## 5. 浏览器兼容性

推荐 Chrome / Edge / Firefox 最新版本。
IE 不支持 Path2D SVG 字符串构造，图标将回退为 ☎ 文字占位。
